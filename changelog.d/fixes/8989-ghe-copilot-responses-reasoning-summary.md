- **fix(executors):** GitHub Copilot / GHE Copilot `/responses` requests now inject `reasoning.summary` when an effort is set and no explicit summary was requested, so clients see visible reasoning instead of encrypted-only blocks. Measured against a live GHE Copilot /responses endpoint (gpt-5.6-luna): visible summary text is 51 chars with `"concise"`, 457 with `"auto"`, 960 with `"detailed"` — in every mode exactly one of two reasoning items remains encrypted (`encrypted_content`, bound to the upstream item/organization; never recoverable by a proxy). The injected value defaults to `"concise"` and can be changed per deployment via the `OMNIROUTE_RESPONSES_REASONING_SUMMARY` env var (`concise` | `auto` | `detailed`); invalid values fall back to the default instead of being forwarded (the upstream rejects bogus values with HTTP 400 `unsupported_value`). Covers both the `reasoning` object form and top-level `reasoning_effort` (OpenAI-shaped bodies).
