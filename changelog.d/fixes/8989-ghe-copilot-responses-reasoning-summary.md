- **fix(executors):** GitHub Copilot / GHE Copilot `/responses` requests now inject `reasoning.summary: "concise"` when an effort is set and no explicit summary was requested. Measured against a live GHE Copilot /responses endpoint (gpt-5.6-luna): `"auto"` leaves the summary choice to the model per reasoning block, so encrypted private reasoning (and the ENCRYPTED_REASONING_PLACEHOLDER) still streamed intermittently; `"concise"` forces a visible summary for every block and fixes the intermittent encrypted-reasoning placeholder shown for `gpt-5.x` models. Covers both the `reasoning` object form and top-level `reasoning_effort` (OpenAI-shaped bodies).
