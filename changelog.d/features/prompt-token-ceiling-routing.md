- **feat(combos):** a combo step can set `maxPromptTokens` — the largest prompt it may serve. A request whose estimated prompt exceeds it skips that step and falls through to the next target, so a model with a long-context price tier (GitHub Copilot bills Claude Haiku 5.5 at 5x above 100k prompt tokens, cache reads included) stays inside its cheap tier instead of silently costing five times as much. The comparison uses the calibrated local estimate (the chars/4 messages + tools + system + instructions breakdown scaled by the learned actual/estimated ratio) with an optional per-combo `promptTokenSafetyFactor` for the cold-start margin; when every target is over its ceiling the request fails with a 400 `prompt_token_ceiling_exceeded` naming each ceiling and the estimate that tripped it.
